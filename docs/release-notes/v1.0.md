## About this release

This release of Du is was developed for use with [Deven 1.0](https://github.com/APrettyCoolProgram/Deven).

## NEW

### DuJson.ExportJson.cs

Handles exporting data as JSON.

* **ToLocalFile()** - Export data to a local JSON file, either formatted or unformatted.

### DuJson.ImportJson.cs

Handles importing JSON data.

* **FromLocalFile()** - Import JSON data from a local file.

### SHFB-Du project

Initial implementation of a Sandcastle Help File Builder project for generating documentation for the Du library.
